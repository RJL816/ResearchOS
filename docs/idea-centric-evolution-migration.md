# Idea 中心的研究演化：语义与迁移

原系统的 `ideas` 和 `idea_versions` 表实际承载可验证假设及假设版本，旧图谱以假设版本为节点；`research_ideas` 已保存完整研究思路，但此前没有自己的状态、版本和演化边。两者不能按名称推断为同一对象。实验与证据仍使用现有实体，并可由人工关联研究 Idea。

本次新增研究 Idea 的生命周期与决定依据、不可变版本快照，以及 Idea 之间独立的演化关系。演化关系记录类型、原因、触发方式、来源与可选实验；允许未知、讨论启发、成本、直觉、失败排查及恢复旧思路，不根据实验结果自动改变 Idea 状态。Idea 主图展示全部状态，旧假设版本图仍可访问。

迁移使用增量 Alembic：不删除或合并旧假设、版本、实验与证据；为已有研究 Idea 创建初始快照；旧假设和实验保持原有归属，对未归属数据提供人工关联入口。新研究报告保留原文，先用外部助手按本地引用整理，再由应用模型分段解析、人工审核，确认后在同一事务中写入；同一原文重复导入会被拦截。标题相同仅提示候选，不能自动合并。

API 密钥由 Windows DPAPI 加密并绑定当前用户，存放在应用数据目录；设置接口不会返回密钥。密钥只会发给用户配置的模型服务，无法解密时需要重新输入。旧版只存在进程内的密钥无法自动继承，需要升级后输入一次。
