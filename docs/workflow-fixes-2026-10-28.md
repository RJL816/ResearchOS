# 科研工作流修复说明

本轮以“研究问题 → 假设版本 → 实验计划 → 指标与证据 → 修订或下一步”为主线，保留已有假设版本、证据和对话来源的数据结构。

## 已落实的交互

- 项目工作台成为创建后和继续研究的入口；增加项目编辑、下一步事项和材料整理入口。创建、删除和切换项目同步更新全局上下文；详情、审核页按实际归属显示项目。
- 假设详情及图谱节点中可以安排针对特定版本的实验、创建新版本、关联证据、手动修改研究状态、维护笔记和下一步事项。新版本从当前正文继续编辑，历史版本保持不变。
- 实验详情可以编辑计划、状态、结果、参数和验证目标，并补录指标。验证目标与证据判断分开；关联证据不会自动将假设标成已验证。
- 下一步事项有独立完成状态，可完成和重新打开，刷新后保留。总览优先显示真实未完成事项及实验计划。
- AI 审核增加项目级历史队列，恢复同一讨论的历次分析；会话按 conversation_id 查找最新任务。刷新可恢复审核入口，失败后可返回讨论重新分析。
- 提案编辑按类型提供目标假设、关系端点和研究状态选择；来源消息按会话顺序标号。接受后的图谱预览模拟新增版本、关系和状态，应用后可返回工作台或定位图谱。
- Agent 预览在隔离数据库中使用真实导入流程，能解析同批新假设、新实验的引用；修改输入或切换模块后旧预览失效，必须重新预览。
- 指标对比统一同一指标的取值范围和真实 step 坐标；选择实验与全选均限制为最多四项。
- 桌面数字路由读取实际地址，修复占位页面校验、内部跳转和刷新问题，并处理静态页面初始化的一致性。手动外观选择不再被系统主题覆盖。

## 数据及桌面产物

数据库迁移新增实验 target_version_id 和笔记 is_done，不改写已有研究正文。现有本地库已迁移，核对前后为 4 个项目、7 个假设、11 个假设版本、6 个实验、6 条笔记，外键检查通过。

迁移前内容备份：`backend/backups/research_os-before-workflow-20261028-164109.db`。

桌面数据库改存用户应用数据目录，首次启动用 SQLite 在线备份方式复制旧安装目录中的数据，保留原库。显式指定迁移数据库的调用不再被默认设置覆盖。已使用打包后端验证旧库复制和升级。

已生成本地 Windows 安装包：`desktop/release/workflow-fix/ResearchOS-Setup-0.4.1.exe`。未上传或发布到 GitHub。

## 验证

- 后端 91 项测试通过，包括 8 项新增跨流程回归；测试使用隔离数据。
- 前端 lint、类型检查、Web 生产构建和桌面静态构建通过。
- 浏览器实际操作：创建项目和假设、安排实验、更新结果、补录指标、关联证据、完成下一步并刷新、修订版本、验证导入预览失效、进入审核队列。
- 隐藏 Electron 窗口实际操作：数字路由直接打开和刷新、内部跳转、保留多次分析历史、编辑并接受提案、预览与应用、回到对应记录、在详情切换项目、刷新恢复正确会话审核入口。另外验证图谱节点内创建、完成下一步事项，以及工作台标签切换和刷新恢复。上述验证没有页面运行错误。
- 打包后的后端实际启动，健康检查及旧库升级通过。

## 尚未覆盖的产品建设

这轮没有调用在线 GLM，因此外部模型服务的质量、凭证和网络连通性不在通过范围内。时间线仍以现有实体记录为主，尚非完整研究事件日志；应用内模型配置、长文本草稿恢复、主指标定义及大量实验的批量加载仍可继续完善。下一步事项暂沿用已有 Next:/下一步: 笔记约定，并新增完成字段；尚未改为独立任务系统。
